# ROUAA CORE V47A — EVENT-LOCAL SEMANTIC BINDING

`SemanticClaimV1` separates publisher identity from subject-entity claims.

A subject entity, temporal value, or event state is CONFIRMED only if its
proof is in the primary structural segment that contains the fact evidence.
Signals from neighbouring segments, headings, URLs, source names, or other
evidence remain context and cannot independently confirm an event-level claim.

The V47A suite covers six regressions: entity, date, and state claims are
rejected when present only in adjacent context and accepted when present in the
primary fact segment. This is a safety foundation, not a population uplift.
