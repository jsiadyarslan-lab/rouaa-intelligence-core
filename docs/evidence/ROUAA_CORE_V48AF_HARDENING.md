### Task 1 — Alias-Length Bug Fix
V2's `_detect_semantic_role` used `len(aliases[0])` for the slice window regardless of which alias was actually matched. When the matched alias differed from `aliases[0]` (e.g., candidate FX matched via "foreign exchange" not "fx"), the slice window was wrong and MODIFIER detection missed.
**V2.1 Fix:** `evaluate_evidence_vector_v21` tracks the matched alias and passes it to `_detect_semantic_role_v21` as the `matched_alias` parameter. The slice window uses `len(matched_alias)` (the actual matched alias length) plus a constant 25-char window.
