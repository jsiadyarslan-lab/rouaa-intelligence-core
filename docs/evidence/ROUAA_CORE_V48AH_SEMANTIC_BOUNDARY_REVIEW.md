**Question:** Is `SUBJECT/CONTEXT/MODIFIER` a lexical property (local text) or a relational property (candidate + event + document context)?
**Answer:** `RELATIONAL_PROPERTY`
**Reason:** The majority of cases (22/24) require either document context (B=15), model redesign (C=0), or are genuinely irreducible (D=7). Only 2 case(s) are solvable by deterministic local evidence (A). This indicates that SUBJECT/CONTEXT/MODIFIER is NOT a lexical property that can be inferred from local text alone. It is a RELATIONAL property — a relationship between candidate + event + document context. The current detect_role() → SUBJECT/MODIFIER/CONTEXT abstraction is INSUFFICIENT because it only checks grammatical subject (syntactic), not semantic subject (what the event is about). The model needs a multi-relational approach.
### Recommended Model
```Multi-relational Subject Adjudication Model:
  Candidate
    ├── Event relation (is the candidate the grammatical subject of the event verb?)
    ├── Measurement relation (is there a measurement that describes the candidate?)
    ├── Syntactic relation (is the candidate a noun modifier?)
    ├── Document context (is the document about this candidate? — TOPIC dimension)
    ├── Competing candidate (is there another candidate with stronger evidence?)
    └── Evidence strength (how strong is the combined evidence?)
          ↓
    Subject adjudication
          ↓
    TRUE_SUBJECT / FALSE_BINDING / AMBIGUOUS / CONTEXT_ONLY```### Strategic Decision
